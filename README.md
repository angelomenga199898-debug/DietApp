# DietApp

Diario alimentare installabile (PWA): pasti, calorie, proteine, acqua, passi e peso, con stima giornaliera del consumo calorico.

- I dati restano sul dispositivo dell'utente (localStorage), nessun account.
- Database offline di alimenti con valori medi indicativi.
- Ricerca online e codici a barre con i dati di [Open Food Facts](https://world.openfoodfacts.org) (licenza ODbL).

Pubblicazione: sito statico, nessun comando di build; la cartella da pubblicare è la radice del repository.
